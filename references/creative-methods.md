# 创意方法

风格基因守住气质，创意方法负责**每次想出不一样的东西**。这一章在第 2 阶段（概念）和第 3 阶段（原型）使用。

## 母题从哪里来：先找过程，再找形

柔性秩序的母题是**一个过程**，而不是一件东西：图形要讲的是“正在发生什么”。所以先找品牌身上正在发生的变化，再问这个变化能不能由几个部分之间的关系讲出来。用下面六组问题去问这个品牌：

1. **业务的过程**：这家公司每天把什么变成什么？是从一到多、从多到一、从小到大、从合到分、从散到聚，还是从无到有？这个过程的中途是什么样子？
2. **名字里的动作**：逐字拆开名字（中文取字义、读音、典故，英文取词根），里面有没有一个动词、一个正在进行的变化？**取意，不取字形。**
3. **用户的经历**：一个客户从第一次接触到离不开，经历了哪几步变化？哪一步最关键？
4. **节律与累积**：服务一次一次发生时，有什么在重复、在递进、在累积、在扩散？
5. **时间与地方**：这个品牌所在的地方、季节或时刻里，有什么过程正在发生，而且只在那里才有？
6. **性质与感受**：如果这个品牌是一种会变化的材料，它变化的方式是什么——长、展、聚、流、叠，还是分？

答案要从这个品牌的事实里来，不要从本 skill 的文字里来：本 skill 有意不举具体的东西，因为举出来的东西会被当成答案。先列出**至少 10 个候选**，覆盖**至少三组**问题，每个候选写成“从 ___ 到 ___ 的过程”，再挑。字形（汉字、字母、标点、数字的样子）不是默认来源：每轮 5 个概念里，来自字形的最多 1 个，而且画出来第一眼必须是图形（见 `craft.md`“母题来自字形时”）。

列完候选之后，再读 `exemplars.md` 和 `cases/index.md`，用它们划掉撞题和惯性的候选。

## 七种方法

### 1. 把一个过程排成一个图形
挑出过程里的几个阶段，让它们同时出现，按过程的方向排成一个整体。看的人沿着方向读，就读出了“先发生什么，后发生什么”。（philosophy.md 第 1、2 条）
- 怎么做：写下过程的 3–7 个阶段；决定排列的方向（回旋、线性、环抱、堆叠……）；让每个阶段的大小或连接沿方向有序变化。
- 案例：EonPoint 把一次分裂的几个阶段沿逆时针排成一圈，读成一个连续的过程。

### 2. 先写规则，再出形
设计的对象是规则：先写出三条以上规则，再由规则生成形；修改时改规则，不改单个形。（philosophy.md 第 4 条）
- 怎么做：从这些规则类型里挑——比例递进、等距、守恒、轨道、递变、旋转；每条规则写成一句话和一个参数；用代码生成。
- 案例：EonPoint 的两条轨道与三向轴、尺寸的固定递进、面积守恒、颈部递变，全部写成参数。

### 3. 最小偏差
规则精确成立之后，每个部分只保留最小的个体偏差，让它活起来；或者反过来，从一个不规则的草图出发，求出“让规则成立所需的最小改动”。（philosophy.md 第 5、6 条）
- 怎么做：先让规则完全成立，看它是否变僵；变僵就逐个加回小偏差，直到不僵为止。偏差要小、要能说出范围。
- 案例：EonPoint 中间有一版把所有部分吸附到规整的点阵上，用户说“过于规整，失去了一些设计的美感和灵动性”；最终版用最小偏移求解，规则精确成立，外观几乎不变。

### 4. 连接即形
部分与部分之间的连接是形的一部分：用柔软的过渡把它们长在一起，让连接本身也说出过程的阶段（粗、细、断）。（philosophy.md 第 6、7 条）
- 怎么做：连接用相切的过渡构造；连接的粗细沿过程方向变化；检查每一处接缝是否连续。
- 案例：EonPoint 的连接是相切的颈，沿分裂方向逐渐变细，直到断开。

### 5. 只打开一处
在一个有秩序的整体里，只让一处关系被打开，让它成为全部焦点，也成为故事的结尾或开头。（philosophy.md 第 8 条）
- 怎么做：先决定打开的方式（离开、留宽、不同的连接、破格）；再让它的距离和方向也服从规则；最后才决定是否用强调色加强。
- 案例：EonPoint 让一个最小的部分沿切线方向离开主体，“将触未触”，它是全套唯一着色的地方。

### 6. 节律与唯一的破格
间隔用统一的节律，只在一处打破；被打破的地方就是开口、方向或焦点。（philosophy.md 第 3 条）
- 怎么做：间隔写成规则（相等、递进、或固定比例）；只允许一处例外，并说出例外的比例。
- 案例：EonPoint 的三处分离缝隙完全相等，左侧开口取缝隙的黄金比倍数，成为回旋的入口。

### 7. 软形硬字
字从零绘制，几何、安静、利落，与柔软的图形形成对比；只向图形借一处小细节。（philosophy.md 第 7 条）
- 怎么做：字的骨架与笔画按 `craft.md` 定制；做视觉修正；只选一处呼应，其余全部收住。
- 案例：EonPoint 的字标“素”，中英文都没有装饰；唯一的呼应是字里的点画与图形的部分同为正圆，其中一处用了强调色。之前带装饰细节的一版被用户否定，理由是太复杂、繁琐。

**加分：让过程动起来。** 好的母题本身就是一段动作：动态就是把过程从头到尾播一遍，终点帧回到标志（见 `style-extension.md`）。

## 走出图解：本风格偏爱的手法

七种方法帮你找到**想法**；想法第一次画出来，往往只是过程的图解——像一张说明图，或者像一个常见的图标。第 3 阶段要用 `craft.md` 手法库里的手法，把它变成一个**只属于这个品牌的图形**。柔性秩序最常用这几种：

| 手法 | 在本风格里的意思 | EonPoint 中的体现 |
|---|---|---|
| 生长 · 定格 | 把一个过程定格在中途，让静止的图形里看得出下一步 | 定格在分裂进行到一半、最后一个部分刚刚离开的时刻 |
| 循环 | 过程首尾相接，排成一圈，读起来没有终点 | 几个阶段沿逆时针排成回旋 |
| 阵列与旋转对称 | 隐藏的骨架：几个部分按旋转关系排布，再各自保留小偏差 | 两条轨道、三向轴、整体扭转，每个部分有不超过几度的偏差 |
| 精确的关系 | 尺寸、间隔、面积之间有量得出的关系——这是“隐秩”的落点 | 缝隙等距、开口取黄金比、面积守恒 |
| 一处偏差 | 在秩序里只留一处例外——这是“离”的落点 | 一个部分离开，其余都在规则里 |
| 归纳成面 | 几个部分合成一个完整的外形，靠面站住，而不是靠线 | 全部为实心的面，模糊后是一个团块 |

截取与负形同样可用。每个原型写明用了哪一种。用户想把方向往某种气质上拧（更安静、更有生命力、更有秩序、更温暖、更国际化……）时，先查 `exemplars.md` 末尾“按想要的气质去看哪一路”，借那一路作品的方法，再动形。**手法服从简报**：本风格偏爱的手法如果把形推向简报里的禁忌，换一种手法。

**转译时守住图形，也守住风格。** 柔性秩序的辨识度来自一个完整的外形、一个读得出的过程和唯一打开的一处，不来自部分的数量或颜色。两头都不要走：不要为了“丰富”“讲全业务”加部分，让图形变成图表或纹样；也不要为了“简洁”把部分减到只剩一个形加一个小元素，让过程消失。小尺寸时，可以减少部分、加宽间隔，单独做一个小尺寸版，主标志保持完整。转译之后，回到 `style-dna.md` 的整体试金石再看一次。

## 概念卡格式（第 2 阶段，每轮 5 张）

```
C<编号> · <概念名>（两到四个字）
母题：      <一个过程：从 ___ 到 ___>；来自 <业务的过程 / 名字里的动作 / 用户的经历 / 节律与累积 / 时间与地方 / 性质与感受，具体到哪件事>
一句话：    <这个标志讲的过程，和它对品牌意味着什么>
形：        <附一张黑白速写；外形、面、几个部分、排列方向；让概念成立的客观事实>
规则：      <至少一条，写成一句话：比例递进 / 等距 / 守恒 / 轨道 / 递变 / 旋转>
打开的一处：<哪里打开、以什么方式；去色后是否仍是焦点>
自查：      <第一眼读成什么（图形感）；剪影最像什么、签名在哪（辨识度）；准备用哪种转译手法>
越过：      <第一反应是什么；为什么越过>
方法：      <七种方法中的哪几种>
旋钮：      <造型语言 / 部分数量 / 过程的种类 / 强调的方式 / 构图（色彩到第 5 阶段再定）>
风险：      <公共符号撞车（这一阶段就查）、行业俗套、在最小尺寸与单色下是否成立>
延展与参照：<能否长成体系、能否动起来；最接近的思想来源，可在本风格参照之外>
```

一轮的 5 张卡，母题（过程）必须彼此不同；至少 2 张的**主造型语言**与 `cases/index.md` 里的都不同。主造型语言指视觉上占主导的那一种——面积最大或最先被看到的那个。

## 防止同质化

- **候选要宽**：候选母题覆盖至少三组问题。同一个品牌反复做，AI 越过第一反应后落脚的“第二反应”也常常一样；来源越宽，越容易走到第三步。
- **案例只借方法，不借形式**：`cases/` 里出现的具体形状、过程、颜色、字，都是那个品牌的答案，不是本风格的规定。
- **母题与安排都不重复**：每轮的过程彼此不同，也不能与 `cases/index.md` 登记的真实案例相同；案例里群与离的**具体安排**（几个部分怎样排、哪里打开、怎样打开）也不复用——换了品牌、换了故事，安排一样，仍然是在重复案例。本章不举虚构品牌的例子——例子会把同行业的项目锚住。
- **造型语言要轮换**：“群”不一定是几个分开的体；带、折、瓣、负形、模块都能组成一个群。一轮里不要五张卡都用同一种造型语言。
- **旋钮要拧**：这是对**整个项目**的要求——最终方案至少两个旋钮与所有案例明显不同；单张概念卡不必每张都满足（见 `style-dna.md`）。
- **警惕默认答案**：本风格的基因（柔、群、离、行）会把 AI 推向某几类反复出现的形；读过的示范和案例也会被不自觉地复述。这里不点名这些答案——点名反而会让人更容易想到它们。用 `exemplars.md` 开头的五个方法自己识别：先合上示范再想母题；认得出出处就划掉；能原封不动搬到别的行业就不是答案；一轮里同类形不成双；问一句“这是这个品牌的答案，还是风格的惯性？”
- **按气质判断**：用八条基因和八条自检判断风格，而不是看元素。
- **交付前对比**：把新方案和已有案例放在一起，一眼要能分开。
