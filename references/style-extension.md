> 标志之后的每一页、每一个场景、每一段动态，都由同一套看不见的规则长出来；整套设计里，只亮一处。

## 原则：让规则和过程在更大的尺度上继续成立

柔性秩序的标志靠**群与离**成立（`style-dna.md`）：一群柔软的部分服从一套看不见的规则，只有一处打开。延展不是把标志贴到各处，而是让这套规则和这个过程在一页版面、一套图标、一段动态、一个空间里继续成立：

- **规则延续**：版面的单位、间距、图标的基准，都从标志的规则里取，而不是另起一套。
- **过程延续**：辅助图形、动态、提案的叙事，都是同一个过程的不同阶段或不同速度。
- **只亮一处延续**：一页、一个场景、一段动态里，强调只出现一次。

最容易走样的地方有三处：
- **把过程做成装饰**：把标志的部分撒满画面，变成热闹的花纹，规则和焦点都没了。
- **规则露出来**：为了显得“有体系”，把构造线、网格、轨道处处画出来，整套设计变成图表。
- **默认模板混进来**：渐变、阴影卡片、通用图标、科技感素材图——每一样单独看都“正常”，放在一起就不再是这个风格。

## 1 体系

| 项 | 柔性秩序怎么做 | 为什么 |
|---|---|---|
| 辅助图形 | 两条来路：一是**过程的阶段**——把标志里的几个阶段拆出来，作为安静的单元疏疏地排开，方向一致，颜色比底色只深一点，只在一处出现强调；二是**隐藏的骨架**——把标志的规则（轨道、轴、比例）画成发丝细线，作为背景的秩序。两者都不抢主角，一页里只用一种 | 辅助图形是规则和过程的回声；拆出来的阶段讲同一个故事，骨架说明“秩序在哪里”。抢眼的辅助图形会把群变成纹样 |
| 版式与网格 | 疏；不对称而平衡；间距与留白的单位取自标志里的一个尺寸；大面积留白，内容靠对齐成组。网格存在，但不画出来 | 隐秩：版面的秩序和标志的秩序是同一套，藏在比例里 |
| 字体系统 | 辅助字体与定制字同一种声音：几何或人文的无衬线，安静、利落；层级靠字号与字距拉开，少用加粗；中英文分量一致 | 软形硬字：文字确定，图形才显得柔软而有意 |
| 色彩比例 | 底色（浅的物名色）占绝大部分；第二种浅色做面与分区；主色给图形；深色给文字；强调色面积极小，只给“离”的那一处或页面上唯一的焦点 | 色以物名：一族颜色合成一个温度；强调越少越珍贵 |
| 图片与插画 | 少用。用时选自然光、看得见材料质感、主体安静、有大面积留白的摄影；不用概念插画、3D 渲染和“科技感”素材图 | 图片也要柔与静；素材图会把整套设计拉回行业默认 |
| 图标 | 与标志同一个基准：面为主，转角柔和，曲率连续；粗细与间隔取自标志的规则；不加阴影和渐变 | 图标是标志的家族，同一套规则画出来 |
| 动态的性格 | **动态就是过程本身**：把标志讲的过程从头到尾播一遍——生长、分开、聚合——各部分按规则依次发生，最后那一处打开，终点帧就是标志。节奏平稳，缓入缓出；不弹跳、不闪光、不做无意义的旋转 | 行：标志是过程的定格，动态是同一个过程的完整版；节奏来自规则，不来自效果 |

## 2 场景

| 项 | 柔性秩序怎么做 |
|---|---|
| 最能证明本风格的场景 | 近距离被拿在手里的东西（名片、信纸、包装）：看得见曲线的精度与材料的质感；大面积留白的空间与屏幕（形象墙、官网首屏、发布会背景）：看得出版面的秩序和唯一的强调。优先做这两类 |
| 材料与工艺 | 偏爱天然、哑光、有触感的材料性格：纸、陶、木、布、植物的本色。工艺用来让人感到柔软与精确，而不是炫技；不用高光、镜面与过度的金属效果 |
| 场景示意的气质 | 底色用浅的物名色，平光、柔和的投影、正面或很小的角度；画面里只放标志和必要的元素，道具越少越好。示意图本身也是本风格的一页 |

## 3 提案

| 项 | 柔性秩序怎么做 |
|---|---|
| 版面 | 一页一个想法；大面积留白；图与字分开，各自对齐；每页只有一处强调 |
| 字与色 | 延续定制字和物名色；大部分页面是浅底，少数关键页（封面、转折页、金句页）可以用主色或深色作底 |
| 叙事的语气 | 平静、讲道理、少形容词。从直觉讲到秩序：先讲品牌里的那个过程，再讲找到的规则，最后给出形——像在讲一个被发现的规律，而不是推销 |
| 页面节奏 | 满页（构造图、体系、场景）与空页（一句话、一个形）交替；过程的每一步可以单独成页，像一段慢放 |
| 封面 | 标志或组合加一句话，大面积留白；看封面就感到安静、精确、温和 |
| 证据的呈现 | 构造图是最有说服力的一页：发丝细线、标注少、单色，把规则逐条标出来；过程图把阶段并排展示；测试与审看板整齐地放在后面 |

## 4 规范手册

沿用提案的版面规则：每页一条规范，图例多于文字；尺寸用标志自身的单位标注；构造图与规则清单放在最前面。错误用法同样安静地陈列，一页一种，重点讲“哪条规则被破坏了”。

## 延展试金石

交付第 6–8 阶段前，用这几个问题整体看一遍：

1. 遮住标志，看任意一页提案、一个场景、一段动态：还认得出是这个品牌、这个风格吗？
2. 辅助图形能说出它从哪里长出来吗——过程的哪个阶段，或者规则的哪一部分？一页里是不是只用了一种？
3. **秩序在哪里**：这一页的间距和比例，能说出它来自标志的哪个单位吗？网格是不是藏起来了？
4. **过程在哪里**：动态和提案的叙事，讲的是不是标志里的同一个过程？动态的终点帧是不是标志？
5. 强调在这一页、这个场景里是不是只出现一处？
6. 和标志并排看，有没有哪一样东西的审美不属于本风格（默认模板、素材图、花哨的动效、高光材质）？

## 案例：EonPoint 怎么延展

只借方法，不借形式：这里的分裂阶段、轨道、苔绿与朱色、名片与形象墙都是 EonPoint 的答案，不是本风格的规定。

| 环节 | 案例里怎么做 | 体现了哪条原则 |
|---|---|---|
| 辅助图形 | 两种：“分裂纹样”——把标志里的三个阶段拆成单元，用比底色深一点的颜色疏疏排开，全部朝同一个方向，只在一个空位放一处朱色；“轨道线”——把隐藏的两条轨道和三向轴画成发丝细线，只点一处朱色 | 过程与骨架两条来路；只亮一处 |
| 规范单位 | 安全空间 x = 组合里那个离开的部分的直径；最小尺寸分组合与图形两档 | 规则延续：单位取自标志自身 |
| 版式 | 海报上标志约占画面宽度的五分之一，上下大片留白，一条发丝细线连接图形与字标 | 疏；不对称而平衡；秩序藏在比例里 |
| 字 | 字标“素”：从零绘制的几何无衬线中英文，与图形只共用“正圆的点”一处；另有“轻”“间”两种力度备选 | 软形硬字 |
| 色彩 | 白、生成、石、苔、墨、朱六色，按物名命名；白与生成作底，苔给图形，墨给文字，朱只给离开的那一处 | 色以物名；强调极少 |
| 错误用法 | 八种，各说明破坏了哪条规则：重排部分、把离开的部分贴回、改色、渐变、描边、拉伸、旋转、放在杂乱的底上 | 规则是规范的主语 |
| 场景 | 名片、信纸与信封、木饰面形象墙与导视、官网首屏、移动端启动页、发布会背景、帆布袋与牛皮纸盒与杯子、社交媒体封面 | 近看的纸品与包装 + 大面积留白的空间与屏幕 |
| 提案 | 38 页：从用户带来的直觉讲起，到测量出的隐藏秩序，再到分裂的过程、规则、字与色、体系、场景；构造图与过程图单独成页 | 从直觉讲到秩序；构造图是证据 |
| 动态 | 本项目没有制作动态。按原则推测：各部分依次分裂、沿方向排开，最后那一处离开并着色，停在标志 | 推测，待下一个项目验证 |

图见 `cases/eonpoint-yuansheng/images/`。
