# 测试简报：检验“风格一致，形式不同”

用途：每次修改风格四章后，让 AI 用本 skill 对下面的虚构品牌跑第 1–3 阶段（简报 → 概念配速写 → 推荐概念的原型），检查：
1. **气质是否到位**：通过 `style-dna.md` 的整体试金石与 `philosophy.md` 的自检。
2. **形式是否不同**：三个品牌的母题、造型语言彼此不同，也与 `cases/` 不同。

| 编号 | 虚构品牌 | 简报 |
|---|---|---|
| E1 | 衡泉 Hengquan | 社区净水站连锁：在小区里放自助净水设备，按月订阅；客户是家庭。想要可靠、干净、亲近，不要冷冰冰的工业感。最小使用场景：设备上的 2 cm 贴标与 App 图标 |
| E2 | 拾页 Leafline | 独立出版社兼书店：出版小众译著，也办读书会；客户是读者与作者。想要安静、有书卷气、能经久，不要文艺腔的手写体。最小使用场景：书脊 |
| E3 | 远舟 Farvessel | 跨境冷链物流：生鲜从产地到门店的温控运输；客户是零售企业。想要稳健、高效、国际化，不要箭头和地球。最小使用场景：车身侧面与运单二维码旁 |

第二组（同一组连跑两三轮后换用）：

| 编号 | 虚构品牌 | 简报 |
|---|---|---|
| E4 | 栖木 Perchwood | 儿童木制玩具与早教课程：客户是 0–6 岁孩子的父母。想要温暖、有趣、但不幼稚，不要卡通形象。最小使用场景：玩具上的烙印 |
| E5 | 澄算 Clearcalc | 中小企业财税 SaaS：自动记账与报税；客户是小企业老板和会计。想要可信、清楚、现代，不要计算器和货币符号。最小使用场景：浏览器标签页图标 |
| E6 | 澄响 Chengxiang Acoustics | 声学实验室：为音乐厅和会议室做声学设计与测量；客户是建筑师与业主。想要精确、专业、有艺术气质，不要声波线和喇叭。最小使用场景：报告封面与工程铭牌 |

## 判定

| 检查 | 通过标准 |
|---|---|
| 母题来源 | 每个概念都写明来自名字或业务的哪里 |
| 不同 | 15 个概念（3 个品牌 × 5）中，以案例造型语言为主的不超过 2 个 |
| 跨品牌不撞形 | 三个品牌的推荐原型放在一起，一眼能分开 |
| 旋钮 | 每个品牌至少两个旋钮与案例不同 |
| 结构先行 | 第 3 阶段原型先以黑白成立（风格章声明色彩即结构时，另附带色版本） |
| 流程 | 每阶段结束都等用户确认，并写入 decisions.md |
| 母题能成图形 | 15 个概念中，母题来自字形（汉字、字母、标点、数字）的每个品牌最多 1 个 |
| 速写 | 第 2 阶段每个概念都有黑白速写（用面和外形画），并写了图形感与辨识度自查 |
| 首先是图形 | 推荐原型遮住名字后，第一眼读成一个东西或画面，而不是字、字母、标点或图标；有完整的外形和面 |
| 辨识度（跑到第 3 阶段时） | 每个锁定概念的原型中至少 2 个走出图解、注明转译手法；剪影、反白、十字描述不像常见图标；签名细节在 32 px 仍看得见 |
| 风格 | 转译后的原型仍然符合本风格的基因；没有为了辨识度牺牲风格，也没有拆成几根线 |
| 群与离 | 每个推荐原型都能说出：哪几个部分成群、服从哪几条规则、哪一处打开；去色后焦点仍在 |
| 不复述案例 | 推荐原型的过程与群与离的具体安排都不同于 `cases/index.md`；不是把案例的安排换个颜色或换个外形 |

测试记录写在 `records.md`。**跑测试的 AI 不要读 `records.md`**，以免被以前的结果影响。
